# 产品与交互提案

## 定义

Chrome 扩展：发现当前标签页中已加载或正在播放的视频，展示可下载的规格，并把用户选择的视频保存为本地可播放文件。

“正在播放”用于排序，不构成唯一识别规则；“页面里有视频”也不保证已经加载下载资源。默认入口是当前标签页，先明确来源再选择规格。

暂定名“拾影 / StreamLens”，名称可在定稿时替换。

## 三个方向

| 方向 | 视觉与布局 | 操作方式 | 优势 | 取舍 |
| --- | --- | --- | --- | --- |
| 聚焦视频 | 浅色暖灰、低饱和绿、420px 弹窗、大封面 | 主视频置顶，清晰度直接选择，一键下载 | 主次清晰，适合单视频页面 | 多视频时纵向空间消耗更大 |
| 紧凑列表 | 浅色、小封面、重复行结构、选中项展开 | 看多个视频的标题与时长，再展开清晰度 | 比较更快，不被封面占满 | 开始下载可能多一次选择 |
| 专业侧栏 | 深色、约370px、较短预览、队列入口 | 常驻浏览器侧栏，用下拉选择规格，持续管理任务 | 不受弹窗失焦关闭影响 | 占用网页横向空间 |

建议：以聚焦视频的视觉语言为基础，资源较多时转成紧凑结构；保留可手动打开的侧栏。三个方向的最终组合可按评审结果调整，不自动将任意方案视为已批准。

## 信息层级

1. 来源：当前站点、只针对当前标签页、是否需要授权。
2. 视频：可辨识的封面或中性占位图、标题、时长、是否主播放器/正在播放。
3. 规格：只有真实解析出规格才列清晰度；未知大小直接写未知，估算加“约”。
4. 动作：下载当前所选规格，其他动作收进详情。
5. 后续：后台任务进度和可执行的失败恢复动作。

同视频清晰度是一组选择；不能把每个 TS 分片、音轨和重复请求列为独立“视频”。广告只是启发式标记，始终可手动展开。

## 首个可用版本的目标

| 功能 | 目标与验收 |
| --- | --- |
| 页面探测 | HTML video/source 与网络请求共同发现资源；支持当前页与已授权 iframe；SPA 页面切换更新来源 |
| MP4/WebM 直链 | 原样保存，不强制转码；显示真实文件扩展名 |
| 非 DRM HLS 点播 | 解析播放清单、选择规格、下载分片、必要时合并音视频，输出可播放文件 |
| 主视频排序 | 主播放器、尺寸、有限时长、播放状态和资源关联共同提供置信度；支持手动选择 |
| 资源去重 | 重复请求与分片归到逻辑视频；无证据的不同视频不强行合并 |
| 持续下载 | UI 关闭不打断；任务独立保存与运行；进度明确区分解析/下载/合并/保存 |
| 任务控制 | 暂停/继续、取消清理、可重试错误；没有稳定续传条件时明确从头重试 |
| 文件管理 | 文件名清理、清晰度后缀、系统保存方式；完成后定位文件 |
| 权限 | 按站点请求；需要重新加载才能捕获历史请求时明确告知 |
| 本地优先 | 无账号、无云端转发、无默认遥测；最小化保存页面信息 |

这些是**待实施目标**；现有原型仅证明 UI 与状态交互。

## 后续候选

非 DRM DASH、自定义目录、多个视频批量加入队列、字幕/音轨选择、跨标签页列表、手动导入清单、直播片段录制。大文件或复杂转封装可选本地辅助程序，必须单独明确依赖和安装流程。

## 边界

- 不承诺所有网站；不绕过 DRM、登录或其他访问保护。
- Blob/MediaSource 不是可直接下载的文件，需要找到背后的清单或媒体请求。
- 暂停和浏览器重启后的恢复取决于分片、服务器、链接有效期与输出存储方式；不展示尚未实现的保证。
- 自动输出 MP4 是 HLS MVP 的技术验证点，不是任意编码都能实现的转换承诺。
- 大文件处理应避免整段视频堆入内存；资源极限验证失败时再决定是否提供辅助程序。

## 状态反馈

未发现：建议先播放几秒。权限：只解释所需站点范围。链接失效：保留任务和文件名，重新解析后重试。文件写入失败：保留可恢复临时数据并重新选保存方式。受保护视频：开始前标明不可保存。没有音轨/规格未知：直接呈现，不编造元数据。

## 交互质量要求

- 下载按钮只对应明确视频与规格；添加成功有轻提示并进入任务页。
- 100% 分片已下载不能提前显示“已完成”。
- 可用资源与失败资源均可解释来源；错误给出一个明确下一步。
- 键盘、焦点、对话框、暗色对比、减弱动效与 320px 宽度要验证。
- 插件使用页不暴露 TypeScript、Manifest、Blob 等实现术语；诊断仅在相关错误提示中显示，正常页面不展示资源详情。


## 0.2.8 正式界面

主操作为“点击播放器 → 自动识别 → 按默认画质下载”；清晰度保留可编辑下拉，避免识别时增加一次确认。视频下载仍需用户点击。仅选中播放器可用来源触发自动请求，后台、侧栏和快捷入口共享解析；失败不循环重试。

信息层级：品牌与设置、当前页面/下载任务导航、来源域名、主视频卡片、折叠其他视频。中性底色与白色/深灰卡片，蓝色强调主操作，统一圆角、边界、间距、字重和焦点样式。去掉假封面、资源技术详情和装饰性状态说明。任务仅展示文件名、画质、状态、进度、文件大小、速度与适用操作。
