# README illustrations

`overview-*.png` presents the video overlay and sidebar; `workspace-*.png` presents selected media, task management and settings. Each has an editable SVG source. Chinese and English variants share the same UI depiction.

These images are documentation illustrations based on StreamLens v0.2.8 layout, labels, Lucide icons and theme colors. They use sample titles and abstract vector artwork. They are not browser screenshots or evidence of native Chrome behavior. English captions do not imply an English extension interface; the current product UI is Chinese.

Project artwork is covered by the MIT license. Icons use lucide-react (ISC). No website video, user data or third-party product artwork is included. The README organization draws on LocalSend's language/download navigation and shadcn/ui's concise visual introduction, without reusing their text or artwork.
